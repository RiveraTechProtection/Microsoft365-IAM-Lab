## Microsoft 365 Identity & Access Management Lab — RiveraTech Protection
*Microsoft Entra ID · Microsoft 365 · SharePoint Online · Least Privilege · Access Control*

- Built a simulated Microsoft 365 environment with three fictional employee identities, license assignments, security groups and department-specific SharePoint resources.
- Configured and validated Read, Edit and denied-access permissions across Finance, HR and restricted Payroll resources using effective-permission checks and separate test-user sessions.
- Simulated a Finance-to-HR transfer by revoking obsolete access, assigning new group membership and verifying the former departmental site denied access.
- Isolated Payroll access through a dedicated security group and private SharePoint site; validated authorized document editing and unauthorized access denial.

**Condensed (two-bullet) version:**
- Configured Microsoft Entra ID groups and SharePoint permission boundaries across Finance, HR and Payroll in a simulated Microsoft 365 environment.
- Validated least-privilege access and an employee transfer with Read/Edit/Denied tests, document editing and verified access revocation.
